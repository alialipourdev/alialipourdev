SNAKE ACTION FIX

Added:
.github/workflows/snake.yml

What it does:
- Generates contribution snake SVGs for GitHub user alialipourdev.
- Publishes generated SVGs to the output branch.
- Runs daily, on pushes to main, and manually via workflow_dispatch.
- Uses a lime/green snake palette.
- Keeps the existing README image paths intact.

Important:
GitHub's contribution graph only includes qualifying GitHub activity. The workflow fixes generation and publishing; it cannot invent commits or fill years with no recorded activity.

After uploading:
1. Commit the .github/workflows/snake.yml file to the main branch.
2. In the repository, open Settings > Actions > General.
3. Under Workflow permissions, allow read and write permissions if the repository setting restricts the workflow token.
4. Open Actions > Generate GitHub Contribution Snake > Run workflow.
5. Wait for the run to complete. It will create/update the output branch and its SVG files.
